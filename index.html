Studyingofis Backups

A private desktop backup utility operated by its owner. It creates local backups of an authorized Studyingofis database and uploaded files, then copies them to the owner's private Google Drive.

This website contains application information only. It does not host backups, accept uploads, or provide public access to student or financial records.

Google Drive access

The utility requests only the drive.file permission to create and verify its own backup files. It does not request access to all files in Google Drive. Authorization is performed through Google; Google passwords are never entered into this website.

Operation

Backups run on the owner's Mac when it is awake, signed in, and connected to the internet. The utility verifies archive checksums after upload. It is not a public cloud backup service and does not guarantee uninterrupted operation or zero data loss.

Owner contact: application support. Do not include private records or credentials in public support requests.
