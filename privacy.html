Privacy Policy — Studyingofis Backups

Effective date: 28 October 2026.

Studyingofis Backups is a private, owner-operated desktop utility. It accesses the owner's Google Drive only after explicit Google authorization, using the limited drive.file scope.

Data use

The utility creates backup archives of the authorized source database and uploaded documents. These may contain student, financial and authentication records. Archives are stored on the owner's Mac and in the owner's private Google Drive. Drive account email is checked to ensure the intended destination. Files created by the utility are read back to verify integrity. OAuth credentials are stored locally with owner-only filesystem permissions.

Sharing and retention

Backup contents are not published on this website, sold, used for advertising, or used to train AI models. The utility transmits backup archives to Google Drive for the requested storage and verification purpose. The owner controls retention and deletion. No automatic public sharing is enabled. The owner has chosen unencrypted archives; access to the Mac and Drive account must be protected.

Control

The owner can stop the local schedule, revoke the application's access through Google Account security settings, and delete backup files locally or through Google Drive. Revoking access does not itself delete existing files.

Website

This static information website has no analytics, advertising, forms, or application cookies. Its hosting provider, GitHub Pages, may process ordinary request logs under its own privacy policy. Backup data is never sent to this website or its repository.

The application's use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Owner contact: application support. Do not include private records or credentials in public support requests.
