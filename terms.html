Terms of Use — Studyingofis Backups

Effective date: 28 October 2026.

This utility is for the owner's authorized private backup workflow. It is not offered as a public service. Only data the owner is authorized to access and back up may be processed.

The utility uses existing storage accounts and does not charge a subscription fee. The owner remains responsible for account quotas, access permissions, local disk capacity, source-service authorization and any existing provider charges.

Scheduled runs require an available Mac, signed-in user session and internet connection. Provider outages, revoked permissions, exhausted storage or device failures can interrupt operation. Archive verification confirms integrity, not a completed recovery rehearsal. The owner must review backup status and test recovery in a separate environment before relying on a backup.

The utility does not modify source financial records as part of backup. Restoring production data is a separate, deliberate operation. The owner may discontinue use and revoke Google access at any time.

Owner contact: application support. Do not include private records or credentials in public support requests.
